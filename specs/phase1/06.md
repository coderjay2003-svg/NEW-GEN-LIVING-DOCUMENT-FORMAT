# Module 06 — LDFX Metadata Subsystem Specification

**Specification Version:** 1.0.0
**Status:** Canonical — Approved
**Depends On:** Module 01, Module 03, Module 04, Module 05
**Required By:** Module 07, Module 08, Module 09

---

## 1. Purpose

The metadata subsystem stores all descriptive, administrative, and structural information about an LDFX document that is not part of the document content itself.

---

## 2. Architecture Decision — Single vs Multiple Files

### Decision: Option B — Single `metadata.json`

**Chosen:** A single `metadata/metadata.json` file containing all metadata as a structured JSON document with clearly separated sections.

### 2.1 Options Evaluated

#### Option A — Multiple JSON Files

Multiple files such as `author.json`, `version.json`, `license.json`, `permissions.json`, etc.

**Advantages:**
- Each concern is isolated in its own file
- Individual sections can be updated without rewriting the entire metadata

**Disadvantages:**
- Requires multiple ZIP entry reads to load complete metadata
- Increases the number of required files, complicating validation
- Partial reads can leave metadata in an inconsistent state
- No single source of truth — conflicts between files are possible
- More complex schema evolution — each file has its own version
- Violates the principle of a single authoritative metadata record

#### Option B — Single `metadata.json` (CHOSEN)

**Advantages:**
- Single atomic read — all metadata available after one ZIP entry read
- Single source of truth — no cross-file conflicts possible
- Single schema version governs the entire metadata record
- Atomic write — metadata is either fully updated or not at all
- Simpler validation — one file, one schema
- Consistent with the approach used by EPUB (`content.opf`), NPM (`package.json`), and Cargo (`Cargo.toml`)

**Disadvantages:**
- File can grow large for documents with extensive revision history (mitigated by a size limit and history truncation policy)

## 3. Location and Storage

| Property | Value |
|---|---|
| Path inside ZIP | `metadata/metadata.json` |
| Encoding | UTF-8, no BOM |
| Compression | Deflate |
| Maximum size | 2 MB |
| Schema version field | Required |

## 5. Field Reference

### 5.1 `document` Block

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string | Yes | UUID v4 — must match `manifest.json` `document.id` |
| `title` | string | Yes | Full document title |
| `subtitle` | string | No | Optional subtitle |
| `abstract` | string | No | Short abstract (max 2000 chars) |
| `description` | string | No | Full description (max 10000 chars) |
| `document_type` | string | Yes | Must match `manifest.json` `document.document_type` |
| `language` | string | Yes | BCP 47 primary language tag |
| `direction` | string | Yes | `ltr` or `rtl` |
| `created_at` | string | Yes | ISO 8601 UTC — must match `manifest.json` |
| `modified_at` | string | Yes | ISO 8601 UTC — must match `manifest.json` |
| `published_at` | string | No | ISO 8601 UTC publication date, or `null` |
| `expires_at` | string | No | ISO 8601 UTC expiry date, or `null` |
| `spec_version` | string | Yes | LDFX spec version — must match `manifest.json` |

---

### 5.2 `authors` Array

Each element represents one author.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string | Yes | UUID v4 — unique author identifier |
| `name` | string | Yes | Author display name (PII — handle per privacy policy) |
| `email` | string | No | Author email (PII — optional, may be omitted) |
| `organization` | string | No | Author's organization |
| `role` | string | Yes | `author`, `editor`, `reviewer`, `contributor` |
| `orcid` | string | No | ORCID identifier for academic authors |
| `url` | string | No | Author URL or profile link |

---

### 5.3 `version` Block

| Field | Type | Required | Description |
|---|---|---|---|
| `document_version` | string | Yes | Semantic version of this document revision |
| `revision` | integer | Yes | Monotonically increasing revision counter (starts at 1) |
| `branch` | string | No | Version branch name (e.g. `main`, `draft`, `review`) |
| `is_draft` | boolean | Yes | Whether this is a draft revision |
| `is_template` | boolean | Yes | Whether this document is a template |
| `changelog` | string | No | Human-readable description of changes in this revision |

---

### 5.4 `license` Block

| Field | Type | Required | Description |
|---|---|---|---|
| `spdx_id` | string | No | SPDX license identifier (e.g. `CC-BY-4.0`, `MIT`, `proprietary`) |
| `name` | string | Yes | Human-readable license name |
| `url` | string | No | URL to full license text |
| `custom_license_text` | string | No | Full custom license text if not a standard license |
| `commercial_use` | boolean | Yes | Whether commercial use is permitted |
| `modification_allowed` | boolean | Yes | Whether modification is permitted |
| `distribution_allowed` | boolean | Yes | Whether redistribution is permitted |
| `attribution_required` | boolean | Yes | Whether attribution is required |

---

### 5.5 `permissions` Block

| Field | Type | Required | Description |
|---|---|---|---|
| `allow_printing` | boolean | Yes | Whether the document may be printed |
| `allow_copying` | boolean | Yes | Whether content may be copied |
| `allow_editing` | boolean | Yes | Whether the document may be edited |
| `allow_annotation` | boolean | Yes | Whether annotations are permitted |
| `allow_extraction` | boolean | Yes | Whether content extraction is permitted |
| `allow_accessibility` | boolean | Yes | Accessibility tools must always be allowed — should always be `true` |
| `password_protected` | boolean | Yes | Whether a password is required to open |
| `drm_enabled` | boolean | Yes | Whether DRM restrictions are active |

---

### 5.6 `keywords` Array

Array of strings. Each keyword is a plain text tag. Maximum 100 keywords. Maximum 100 chars per keyword.

```json
["engineering", "specification", "document-format"]
```

---

### 5.7 `categories` Array

Array of category objects for hierarchical classification.

```json
[
  {
    "scheme": "ldfx:document-type",
    "value": "technical-specification"
  },
  {
    "scheme": "dewey",
    "value": "005.7"
  }
]
```

| Field | Type | Required | Description |
|---|---|---|---|
| `scheme` | string | Yes | Classification scheme identifier |
| `value` | string | Yes | Category value within the scheme |

---

### 5.8 `ai_metadata` Block

| Field | Type | Required | Description |
|---|---|---|---|
| `ai_generated` | boolean | Yes | Whether the document content was fully AI-generated |
| `ai_assisted` | boolean | Yes | Whether AI tools assisted in creating the content |
| `ai_model_ids` | array | No | List of AI model identifiers used |
| `ai_content_policy` | string | Yes | `none`, `reviewed`, `verified` |
| `ai_disclosure` | string | No | Human-readable AI usage disclosure statement |

---

### 5.9 `accessibility` Block

| Field | Type | Required | Description |
|---|---|---|---|
| `wcag_level` | string | No | `A`, `AA`, `AAA`, or `null` |
| `has_alt_text` | boolean | Yes | All images have alt text |
| `has_captions` | boolean | Yes | All video/audio has captions |
| `has_audio_description` | boolean | Yes | Video has audio descriptions |
| `has_reading_order` | boolean | Yes | Logical reading order defined |
| `has_aria_labels` | boolean | Yes | Interactive elements have ARIA labels |
| `language_declared` | boolean | Yes | Document language is declared |
| `color_contrast_verified` | boolean | Yes | Color contrast meets WCAG requirements |
| `keyboard_navigable` | boolean | Yes | Document is fully keyboard navigable |

---

### 5.10 `localization` Block

| Field | Type | Required | Description |
|---|---|---|---|
| `default_locale` | string | Yes | BCP 47 default locale |
| `available_locales` | array | Yes | All available BCP 47 locale tags |
| `rtl_locales` | array | No | Subset of `available_locales` that use RTL direction |
| `locale_completeness` | object | No | Map of locale → completeness percentage (0–100) |

---

### 5.11 `revision_history` Array

Each element records one revision event. Maximum 1000 entries. Older entries are archived to a separate file when the limit is reached.

```json
[
  {
    "revision": 1,
    "version": "1.0.0",
    "author_id": "author-uuid-v4",
    "timestamp": "2025-01-01T00:00:00Z",
    "action": "created",
    "summary": "Initial document creation",
    "spec_version": "1.0.0"
  }
]
```

| Field | Type | Required | Description |
|---|---|---|---|
| `revision` | integer | Yes | Revision number (matches `version.revision`) |
| `version` | string | Yes | Document version at this revision |
| `author_id` | string | Yes | UUID of the author who made this revision |
| `timestamp` | string | Yes | ISO 8601 UTC timestamp |
| `action` | string | Yes | `created`, `edited`, `reviewed`, `published`, `archived` |
| `summary` | string | No | Human-readable summary of changes |
| `spec_version` | string | Yes | LDFX spec version at time of revision |

---

### 5.12 `_reserved` Block

Must always be present as an empty object `{}`. Future versions may promote fields from `_reserved` to named fields.

## 6. Validation Rules

| Rule | Severity | Condition |
|---|---|---|
| `metadata.json` missing | Fatal | File not present in `metadata/` |
| `document.id` mismatch | Fatal | Does not match `manifest.json` `document.id` |
| `document.title` empty | Fatal | Empty string or missing |
| `document.language` invalid | Fatal | Not a valid BCP 47 tag |
| `document.created_at` mismatch | Fatal | Does not match `manifest.json` |
| `document.modified_at` mismatch | Fatal | Does not match `manifest.json` |
| `authors` empty | Warning | No authors declared |
| `version.revision` < 1 | Fatal | Revision counter must start at 1 |
| `permissions.allow_accessibility` false | Warning | Accessibility must not be disabled |
| `revision_history` > 1000 entries | Warning | History should be archived |
| `metadata.json` > 2 MB | Warning | Exceeds recommended size |
| `document.id` not UUID v4 | Fatal | Invalid UUID format |
| `_reserved` not empty object | Warning | Contains unexpected fields |
| Unknown root field | Info | Field not in this specification |

# Module 11 — LDFX Page & Content Model Specification

**Specification Version:** 1.0.0
**Status:** Canonical — Approved
**Depends On:** Module 01, Module 03, Module 04, Module 05, Module 08, Module 09, Module 10
**Required By:** Module 12, final_integration

---

## 1. Purpose

This module defines the page model and content node tree that represents all document content in LDFX. It specifies how pages are structured, how content is represented, how layout is defined, and how interactive elements are declared.

The content model is the core of what makes LDFX a living document — it supports rich text, media, interactive components, forms, charts, and AI-powered content within a unified, deterministic, accessible structure.

---

## 2. Page Index

`pages/index.json` defines the ordered list of all pages in the document.

```json
{
  "schema_version": "1.0.0",
  "page_count": 3,
  "pages": [
    {
      "id": "page-uuid-v4",
      "path": "pages/page_001",
      "title": "Introduction",
      "number": 1,
      "visible": true,
      "type": "content",
      "parent_id": null,
      "children": []
    },
    {
      "id": "page-uuid-v4-2",
      "path": "pages/page_002",
      "title": "Chapter 1",
      "number": 2,
      "visible": true,
      "type": "content",
      "parent_id": null,
      "children": []
    }
  ]
}
```

### 2.1 Page Index Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string | Yes | UUID v4 — stable page identifier |
| `path` | string | Yes | Path to page directory inside ZIP |
| `title` | string | No | Page title for navigation |
| `number` | integer | Yes | Display page number (1-based) |
| `visible` | boolean | Yes | Whether page appears in navigation |
| `type` | string | Yes | Page type (see §2.2) |
| `parent_id` | string | No | UUID of parent page for hierarchical documents |
| `children` | array | No | Ordered list of child page UUIDs |

### 2.2 Page Types

| Type | Description |
|---|---|
| `content` | Standard content page |
| `cover` | Document cover page |
| `toc` | Table of contents |
| `section` | Section divider (may have no content) |
| `appendix` | Appendix page |
| `blank` | Intentionally blank page |

---

## 3. Page Directory Structure

Each page is stored in its own directory:

```
pages/page_001/
├── content.json    ← content node tree (required)
└── layout.json     ← layout definition (required)
```

## 4. Layout Definition (`layout.json`)

`layout.json` defines the physical dimensions and layout properties of the page.

```json
{
  "schema_version": "1.0.0",
  "page_id": "page-uuid-v4",
  "width": 794,
  "height": 1123,
  "unit": "px",
  "dpi": 96,
  "orientation": "portrait",
  "margin": {
    "top": 72,
    "right": 72,
    "bottom": 72,
    "left": 72
  },
  "columns": 1,
  "column_gap": 0,
  "background": {
    "type": "color",
    "value": "#ffffff"
  },
  "flow": "block"
}
```

### 4.1 Layout Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `page_id` | string | Yes | Must match page UUID in index |
| `width` | number | Yes | Page width in declared units |
| `height` | number | Yes | Page height in declared units |
| `unit` | string | Yes | `px`, `mm`, `pt` |
| `dpi` | integer | Yes | Dots per inch for physical rendering |
| `orientation` | string | Yes | `portrait` or `landscape` |
| `margin` | object | Yes | Top/right/bottom/left margins |
| `columns` | integer | Yes | Number of content columns (1–12) |
| `column_gap` | number | No | Gap between columns in declared units |
| `background` | object | No | Page background definition |
| `flow` | string | Yes | `block` (top-to-bottom) or `absolute` (positioned) |

### 4.2 Standard Page Sizes

| Name | Width (mm) | Height (mm) |
|---|---|---|
| A4 | 210 | 297 |
| A5 | 148 | 210 |
| Letter | 215.9 | 279.4 |
| Legal | 215.9 | 355.6 |
| Presentation (16:9) | 338.7 | 190.5 |
| Custom | Any | Any |

## 5. Content Node Tree (`content.json`)

The content model is a tree of typed nodes. Every piece of content — text, image, video, form, chart — is a node.

```json
{
  "schema_version": "1.0.0",
  "page_id": "page-uuid-v4",
  "root": {
    "id": "node-uuid",
    "type": "container",
    "children": [
      {
        "id": "node-uuid-2",
        "type": "heading",
        "level": 1,
        "content": [
          {
            "id": "node-uuid-3",
            "type": "text",
            "value": "Introduction",
            "style": {
              "font_family": "font-uuid",
              "font_size": 32,
              "font_weight": "bold",
              "color": "#1a1a1a"
            }
          }
        ]
      },
      {
        "id": "node-uuid-4",
        "type": "paragraph",
        "content": [
          {
            "id": "node-uuid-5",
            "type": "text",
            "value": "This document describes the LDFX format.",
            "style": {}
          }
        ]
      }
    ]
  }
}
```

## 7. Node Schema

Every node shares a common base schema:

```json
{
  "id": "node-uuid-v4",
  "type": "<node-type>",
  "style": {},
  "layout": {},
  "aria": {},
  "script_id": null,
  "visible": true,
  "locale_overrides": {},
  "children": [],
  "_reserved": {}
}
```

### 7.1 Common Node Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string | Yes | UUID v4 — unique within the document |
| `type` | string | Yes | Node type from §6 |
| `style` | object | No | Visual style properties |
| `layout` | object | No | Layout/positioning properties |
| `aria` | object | No | ARIA accessibility attributes |
| `script_id` | string | No | UUID of script that controls this node |
| `visible` | boolean | No | Default `true` |
| `locale_overrides` | object | No | Per-locale content overrides |
| `children` | array | No | Child nodes |
| `_reserved` | object | No | Future extension point |

## 8. Style System

Styles are defined inline on nodes or referenced from a document-level style sheet.

### 8.1 Inline Style Properties

```json
{
  "font_family": "font-uuid",
  "font_size": 16,
  "font_weight": "normal",
  "font_style": "normal",
  "color": "#1a1a1a",
  "background_color": "transparent",
  "text_align": "left",
  "line_height": 1.5,
  "letter_spacing": 0,
  "text_decoration": "none",
  "padding": { "top": 0, "right": 0, "bottom": 0, "left": 0 },
  "margin": { "top": 0, "right": 0, "bottom": 0, "left": 0 },
  "border": null,
  "border_radius": 0,
  "opacity": 1.0,
  "overflow": "visible"
}
```

### 8.2 Style Inheritance

- Styles cascade from parent nodes to child nodes
- Child node styles override parent styles for the same property
- Document-level default styles are defined in `metadata/styles.json` (future module)

## 9. Localization in Content

Nodes support per-locale content overrides via `locale_overrides`:

```json
{
  "id": "node-uuid",
  "type": "text",
  "value": "Hello",
  "locale_overrides": {
    "fr": { "value": "Bonjour" },
    "ar": { "value": "مرحبا" }
  }
}
```

The runtime selects the appropriate locale value based on the active locale. If no override exists for the active locale, the default value is used.

---

## 10. Accessibility in Content

Every node supports ARIA attributes:

```json
{
  "aria": {
    "role": "heading",
    "level": 1,
    "label": "Introduction section",
    "description": null,
    "live": null,
    "hidden": false
  }
}
```

Images must have `alt_text` in the asset index (Module 10 §3.1). Interactive nodes must have `aria.label`.

---

## 11. Script Binding

Nodes may be bound to scripts via `script_id`. The script can:
- Read and modify node properties
- Listen to node events (click, focus, change, etc.)
- Trigger node visibility changes
- Update node content dynamically

Script binding is subject to the permission system defined in Module 09 §3.

## 12. Validation Rules

| Rule | Severity | Condition |
|---|---|---|
| `pages/index.json` missing | Fatal | Required file missing |
| `page_count` mismatch | Fatal | Index count ≠ manifest `page_count` |
| Page directory missing | Fatal | Index references non-existent directory |
| `content.json` missing | Fatal | Required file in page directory |
| `layout.json` missing | Fatal | Required file in page directory |
| `content.json` invalid JSON | Fatal | Parse error |
| `layout.json` invalid JSON | Fatal | Parse error |
| Node `id` not UUID v4 | Fatal | Invalid node identifier |
| Duplicate node `id` | Fatal | Node IDs must be unique across the document |
| Unknown node type | Warning | Forward compatibility — unknown types ignored |
| Image node missing `asset_id` | Fatal | Required field |
| Asset reference not in index | Fatal | Broken asset reference |
| Script reference not in index | Fatal | Broken script reference |
| Interactive node missing ARIA label | Warning | Accessibility requirement |
| Image node missing alt text | Warning | Accessibility requirement |
| `page_id` mismatch | Fatal | `content.json` or `layout.json` page_id ≠ index |

## 13. Consistency with Previous Modules

- Pages stored in `pages/` as defined in Module 04 §2.2
- Asset references use UUID from `assets/index.json` per Module 10 §2.2
- Script references use UUID from `scripts/index.json` per Module 04 §2.4
- Page validation is Stage 9 of the validation pipeline per Module 08 §4
- All JSON files use UTF-8 without BOM per Module 01 §4
- Deflate compression for page JSON per Module 03 §8.1
- `HAS_FORMS` feature flag (Module 02 §4) must be set when form nodes are present
- `HAS_AI` feature flag must be set when AI nodes are present
- Localization uses BCP 47 locale tags consistent with Module 05 §4.2 and Module 06 §5.10
- ARIA accessibility requirements consistent with Module 06 §5.9

🔧 TROUBLESHOOTING

   Problem: \"Server not found\"
   → App not installed correctly
   → Solution: Reinstall or rebuild

   Problem: Port 8080 already in use
   → Another app using the port
   → Solution: Close that app or restart PC

   Problem: Browser won't open
   → No default browser set
   → Solution: Set default browser in Windows Settings
   → Or manually visit: http://127.0.0.1:8080/creator

   Problem: Launcher script won't run
   → PowerShell execution policy blocked
   → Solution: Use .bat file instead or run:
      Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

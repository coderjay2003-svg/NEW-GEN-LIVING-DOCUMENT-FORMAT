Security Architecture

Defense-grade security by design. Cryptographic proof of origin, sandboxed execution boundaries, and zero cloud dependencies.

Effective: September 12, 2026 • Standard Version 2.6.0 • J AI ENTERPRISES

01. Cryptographic ECDSA P-256 Document Signing

Every living document created or compiled with LDOC Studio is signed with a high-assurance ECDSA P-256 curve keypair using the W3C WebCrypto SubtleCrypto API:

  • Upon document compile, the manifest metadata and page blocks payload are serialized and digested using SHA-256.
  • The digest is signed by the author's private key, producing an authentic signature saved to signatures/ecdsa-p256.sig.
  • The author's public key is bundled in JSON Web Key (JWK) format at signatures/public-key.jwk.
  • Upon opening, verifyPackageIntegrityCloud() computes the cryptographic verification locally, alerting users instantly if even a single byte or pixel of the document has been altered.

02. Zero-Privilege Sandbox Isolation

Dynamic living documents execute user-provided code, interactive charts, and WebGL models. To prevent arbitrary code execution:

  • Raw new Function() and eval() are completely banned across all runtime parsers and viewers.
  • All JavaScript widgets, React JSX blocks, and Chart.js code execute inside origin-isolated <iframe sandbox="allow-scripts allow-forms allow-popups"> elements.
  • The iframe is strictly isolated from parent DOM trees, localStorage, cookies, and parent window tokens, communicating solely through sanitized postMessage RPC protocols.

03. Native Desktop Electron Hardening

In the desktop application (packages/ldoc-studio/main.js), security controls are enforced at the native Chromium level:

  • webSecurity: true is enforced to uphold standard Same-Origin Policy.
  • nodeIntegration: false guarantees renderer processes cannot access Node.js APIs or native OS file paths directly.
  • contextIsolation: true prevents prototype pollution between web content and preload scripts.
  • allowRunningInsecureContent: false blocks mixed-content attacks.

04. Air-Gapped & Sovereign Network Compliance

LDOC Studio and the standalone Android APK are engineered to operate in 100% air-gapped environments (SCIF, shipboard, military, nuclear, and financial server rooms). All vendor scripts (React, ReactDOM, Three.js, Chart.js, OrbitControls, GLTFLoader) are bundled locally. The application never requires an internet handshake to view, edit, or sign documents.

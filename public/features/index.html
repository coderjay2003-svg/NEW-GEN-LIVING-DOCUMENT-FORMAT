Open .ldocx Packaging
Deterministic ZIP container with JSON AST, media manifests, and SHA-256 integrity trees. Inspectable by standard CLI tools.
SPEC-02 • EXTENSIBILITY
Universal Plugin & Block API
Extensible TypeScript/JS SDK (@ldoc/sdk) enables developers to create custom reactive blocks, sandboxes, and bespoke widgets.
SPEC-03 • 3D PIPELINE
Draco Mesh Compression
Heavy CAD & 3D models are reduced by up to 92% using Google Draco compression for sub-second edge transmission.
SPEC-04 • COMPILATION
Multi-Target Export Engine
Headless edge compilation outputs print-perfect PDF, standard DOCX, standalone single-file HTML5, or raw AST JSON.
SPEC-05 • OFFLINE FIRST
Cryptographic Portability
Every .ldocx document functions entirely offline. No external server pings required to view, inspect, or execute interactions.
SPEC-06 • SECURITY
Isolated Execution Sandbox
Code executions run in secure iframes with strict isolation and zero filesystem access.

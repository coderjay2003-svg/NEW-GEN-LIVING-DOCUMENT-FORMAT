## 2. In-Studio Native 3D Conversion Engine (`window.LDoc3DConverter`)

### 2.1 Supported File Formats
1. **`.3mf` (3D Manufacturing Format)**: Unpacks OPC ZIP container via `JSZip`, extracts all `3D/*.model` XML descriptors, parses `<vertex>` and `<triangle>` tags, and translates CAD Z-up to WebGL Y-up `[x, z, -y]`.
2. **`.stl` (Stereolithography)**: Auto-detects Binary STL headers (84 bytes + $50 \times N$ triangle records) and ASCII STL facet loops.
3. **`.obj` (Wavefront)**: Full support for vertices `v`, faces `f`, negative indexing, and automatic quad-to-triangle triangulation.
4. **`.glb` / `.gltf`**: Buffer geometry extraction via Three.js loader.

### 2.2 Geometry Pipeline Algorithms
- **Strict Budget Decimation**:
  Mobile and desktop WebGL performance requires a maximum draw-call budget of $\le 35,000$ triangles. When a raw mesh (e.g. 1.5 million triangles) is ingested, the engine applies uniform stride sampling and index remapping:
  $$\text{step} = \left\lceil \frac{N_{\text{triangles}}}{N_{\text{target}}} \right\rceil$$
- **Centering & Scale Normalization**:
  Calculates the axis-aligned bounding box (AABB):
  $$\vec{C} = \frac{\vec{V}_{\max} + \vec{V}_{\min}}{2}, \quad s = \frac{3.2}{\max(\vec{V}_{\max} - \vec{V}_{\min})}$$
  Translates all vertices to $(0, 0, 0)$ and scales to an optimal bounding sphere radius of $1.6$.

| **`scipy`** | `pip install scipy` | KD-Tree spatial nearest-neighbor search, Delaunay triangulation, and convex hull generation. |
| **`pymeshlab`** | `pip install pymeshlab` | Quadric Edge Collapse decimation preserving UV boundaries and high-frequency surface normals. |
| **`open3d`** | `pip install open3d` | Point cloud voxel downsampling, normal estimation, and Poisson surface reconstruction. |
| **`pygltflib`** | `pip install pygltflib` | Direct binary GLB chunk assembly with PBR metallic-roughness material channels. |

## 4. Standalone Python Pipeline Script

This script is dynamically generated by LDOC Studio and can be copied or executed directly:

```python
import zipfile
import xml.etree.ElementTree as ET
import numpy as np
import json

def process_3mf(file_path: str, target_triangles: int = 25000) -> dict:
    """
    Ingests an industrial .3mf package, decimates to the LDOCX budget,
    and returns a normalized WebGL-ready JSON mesh.
    """
    with zipfile.ZipFile(file_path, 'r') as z:
        for name in z.namelist():
            if name.endswith('.model'):
                with z.open(name) as f:
                    root = ET.parse(f).getroot()
                    v = [[float(e.attrib['x']), float(e.attrib['y']), float(e.attrib['z'])] 
                         for e in root.findall('.//{*}vertex')]
                    t = [[int(e.attrib['v1']), int(e.attrib['v2']), int(e.attrib['v3'])] 
                         for e in root.findall('.//{*}triangle')]
                    break

    v = np.array(v, dtype=np.float32)
    t = np.array(t, dtype=np.int32)
    
    # 1. Decimate to <35,000 polygon budget
    if len(t) > target_triangles:
        step = int(np.ceil(len(t) / target_triangles))
        sub_t = t[::step]
        used = np.unique(sub_t)
        remap = {old: new for new, old in enumerate(used)}
        v = v[used]
        t = np.array([[remap[idx] for idx in tri] for tri in sub_t], dtype=np.int32)

    # 2. Auto-center and normalize scale
    center = (v.max(axis=0) + v.min(axis=0)) / 2.0
    v -= center
    max_dim = np.max(v.max(axis=0) - v.min(axis=0))
    scale = 3.2 / (max_dim if max_dim > 0 else 1.0)
    v = np.round(v * scale, 2)

    # 3. Transform CAD Z-up to WebGL Y-up: [x, z, -y]
    v_webgl = np.zeros_like(v)
    v_webgl[:, 0] = v[:, 0]
    v_webgl[:, 1] = v[:, 2]
    v_webgl[:, 2] = -v[:, 1]

    return {
        "vertices": v_webgl.tolist(),
        "faces": t.tolist()
    }
```
